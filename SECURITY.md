# Security Policy

## Supported Versions

`context-compactor` has not published a public release yet. Security fixes are
currently made against the current `main` branch. This policy will be updated
after the v0.1.0 release.

## Reporting a Vulnerability

Use GitHub repository private vulnerability reporting when that option is
available. If it is not available, open a public issue that requests a private
reporting channel without including sensitive details.

Do not include exploits, secrets, credentials, or complete prompts in a public
issue. Keep the initial public report limited to the affected area and a
request for a private channel.

No response-time commitment is made by this policy.
